# 后续应用

## Qt：apps/desktop-qt

独立 CMake / Qt 项目，负责串口设备发现、配置编辑、配对辅助和固件刷写。以 `protocol/v1` 为合同，不依赖固件内部实现。首版 HTTP 可用于联网配置；串口业务协议尚未实现，后续增加适配层复用 ConfigStore，而非新增另一套配置规则。刷机可封装 esptool。

## Go：apps/macos-agent

独立 Go module，负责 Mac 在线状态与唤醒后的任务协作，可报告用户会话状态。不能把普通后台服务等同于安全登录界面的输入权限，图形桌面解锁仍由硬件 HID 与人工实测决定。

## 演进

先完成目标 Mac 的睡眠与重连验收，再开发 Qt / Go。可后续增加串口协议、配置迁移、签名固件和设备证书。没有需求时不提前引入多 Broker、云端设备平台或通用插件框架。

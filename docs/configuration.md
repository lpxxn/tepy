# 配置与恢复

配置版本为 `v: 1`，以单条 JSON 存储于 NVS，写入成功后才替换内存配置。未知版本保留原数据并启动失败，不自动擦除 NVS。网络配置保存后重启生效。

| 字段 | 默认 / 范围 |
| --- | --- |
| wifi.ssid | 空，最长 32 字节 |
| wifi.password | 空（开放网络）或 8–63 字节 |
| mqtt.uri | 空；mqtt:// 或 mqtts://，最长 256 字节，不内嵌用户名密码 |
| mqtt.username / password | 空，分别最长 128 / 256 字节 |
| mqtt.ca | 空时使用证书包；可填 PEM CA，最长 8192 字节 |
| ntp_server | pool.ntp.org，最长 128 字节 |
| key_delay_ms | 20；5–200 ms，按下与释放分别等待 |
| admin_password | 自动生成；修改需 16–64 个非空白 ASCII 可打印字符 |

密码省略表示保留，空字符串表示清除；SSID 为空表示不连接 Wi-Fi。配置读取只返回非敏感字段及 `*_set` 布尔值。CA 证书可公开读取，私钥不属于此接口。

热点 SSID 为 `Tepy-<设备后六位>`，使用随机 WPA2 密码；管理口令独立生成。首次启动打印凭据，普通启动不重复打印。运行时长按 BOOT（默认 GPIO0）三秒开启热点并向串口重新输出本地恢复凭据；不要在上电时一直按住 BOOT，否则可能进入 ROM 下载模式。

启动后 30 秒仍无法连接 Wi-Fi会开启恢复热点，继续尝试连接；不会清除原来的配置。已建立连接后掉线也会重试并在超时后提供恢复热点。通过网页恢复的手动热点保留至重启。

首版 NVS 未启用硬件加密；持有设备 Flash 访问权的人可以读取网络与管理凭据。Mac 密码不写 NVS。首版不烧写安全启动或 Flash 加密 eFuse，方便串口恢复。
